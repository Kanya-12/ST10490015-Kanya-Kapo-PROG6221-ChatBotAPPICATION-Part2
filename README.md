# ST10490015-Kanya-Kapo-PROG6221-ChatBotAPPLICATION-Part1
POE Part 1 – KanyaShield Cybersecurity Awareness ChatBot

## Overview
**KanyaShield** is a Cybersecurity Awareness Chatbot developed in **C#**.  
The chatbot is designed to educate users about online safety, cyber threats, and best security practices through an interactive console application.

---

## Features
- **Voice greeting** using audio playback (`Chatbot greeting.wav`)
- **ASCII art logo** display with loading animation
- **Interactive chatbot** with user input
- **29 cybersecurity awareness questions** with curated answers
- **Typing animation** for realistic user experience
- **Input validation and error handling**

---

## Purpose
The purpose of this chatbot is to:
- Educate users about cybersecurity  
- Promote safe online behavior  
- Help prevent cyber threats such as phishing, malware, and scams  

---

## Technologies Used
- **C#**  
- **.NET Console Application**  
- **GitHub (Version Control)**  
- **GitHub Actions (CI/CD)**  

---

## How to Run
1. Open the project in **Visual Studio**.  
2. Build the solution.  
3. Run the application.  
4. Interact with the chatbot using:
   - Numbers (1–29)  
   - Or typed questions  

---

## Example Topics Covered
- Phishing attacks  
- Strong passwords  
- Malware & ransomware  
- Safe browsing  
- Social engineering  
- Data privacy
